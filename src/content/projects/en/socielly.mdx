Socielly was my bachelor project in web development in 2020, and it got a 10 (equivalent to a B). I built it before AI coding tools existed, so all of it is written by hand. The code is on GitHub with commits from December 2020, both [the client](https://github.com/CasperHavelykke/sonet-client) and [the server](https://github.com/CasperHavelykke/sonet-server).

## What you could do

Socielly was a social network in the style of Facebook. You could create a profile, update your details and upload a profile picture.

## How it's built

- **Frontend:** React with Apollo Client, React Router and Semantic UI.
- **API:** GraphQL with Apollo Server on Node.js and Express.
- **Data:** MongoDB with Mongoose.
- **Sign-in:** JSON Web Tokens and passwords hashed with bcrypt.
- **Images:** uploaded straight through GraphQL.

The server ran on Heroku and the client on a web host.

## What I learned

The project taught me the architecture all the way from the database through the backend to the frontend, and how the layers talk to each other.
