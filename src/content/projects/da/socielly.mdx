Socielly var mit bachelorprojekt på webudviklingsuddannelsen i 2020, og det fik 10. Jeg byggede det, før der fandtes AI-værktøjer til kode, så det hele er skrevet i hånden. Koden ligger på GitHub med commits fra december 2020, både [klienten](https://github.com/CasperHavelykke/sonet-client) og [serveren](https://github.com/CasperHavelykke/sonet-server).

## Det kunne man

Socielly var et socialt medie i stil med Facebook. Man kunne oprette en profil, opdatere sine oplysninger og uploade et profilbillede.

## Sådan er det bygget

- **Frontend:** React med Apollo Client, React Router og Semantic UI.
- **API:** GraphQL med Apollo Server på Node.js og Express.
- **Data:** MongoDB med Mongoose.
- **Login:** JSON Web Tokens og adgangskoder hashet med bcrypt.
- **Billeder:** upload direkte gennem GraphQL.

Serveren kørte på Heroku og klienten på et webhotel.

## Det lærte jeg

Projektet lærte mig arkitekturen hele vejen fra database over backend til frontend, og hvordan lagene taler sammen.
